# سرور همگام‌سازی «الآن / Now»

با این سرور، یادآوری‌ها و دسته‌بندی‌ها و مناسبت‌های شخصی و تصاویر بین برنامهٔ ویندوز و موبایل همگام می‌شوند.
فقط **پایتون ۳** لازم است (چیز دیگری نصب نمی‌شود).

## اجرا روی کامپیوتر ویندوز
1. پایتون را نصب کن (python.org). موقع نصب تیک «Add Python to PATH» را بزن.
2. فایل `now_sync_server.py` را در یک پوشه بگذار.
3. در همان پوشه Command Prompt باز کن و بزن:

       python now_sync_server.py --port 8787

   یا روی `run_server.bat` دوبار کلیک کن.
4. آدرس IP کامپیوتر در شبکهٔ خانه را پیدا کن (دستور `ipconfig`، مثلاً `192.168.1.5`).
5. اگر ویندوز دربارهٔ فایروال پرسید، «Allow» را بزن.

## وارد کردن در برنامه‌ها
در **پروفایل ← همگام‌سازی ویندوز و موبایل** هر دو برنامه:
- آدرس سرور: `192.168.1.5:8787` (آدرس سرور خودت)
- کلید: یک رمز دلخواه، حداقل ۸ نویسه (در هر دو برنامه **دقیقاً یکی**)

بعد «ذخیره و همگام‌سازی» را بزن. از این به بعد خودکار همگام می‌شود.

## استفاده بیرون از خانه
گوشی فقط وقتی به سرور می‌رسد که سرور برایش در دسترس باشد. گزینه‌ها:
- سرور را روی یک سرور مجازی (VPS) داخل ایران بگذار و `--port` را در فایروالش باز کن؛
- یا روی همان Wi-Fi خانه کار کن (همگام‌سازی هر بار که به شبکه برگردی انجام می‌شود).

## توضیحات
- داده‌ها در پوشهٔ `now_data` کنار فایل ذخیره می‌شوند؛ از آن نسخهٔ پشتیبان بگیر.
- هر کلید فضای جدا دارد. برای محدود کردن کلیدها: `--keys کلید-اول,کلید-دوم`
- ارتباط ساده (HTTP) است. اگر از اینترنت استفاده می‌کنی، پشت یک پروکسی HTTPS (مثل Caddy) بگذارش.
- اگر دو دستگاه هم‌زمان یک مورد را عوض کنند، **آخرین تغییر** (بر اساس ساعت دستگاه) می‌ماند؛ ساعت دستگاه‌ها را درست نگه دار.
